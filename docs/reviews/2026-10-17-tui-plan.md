## Decisions

- R5: move to FOLLOWUP_TASKS.
- R18: the external editor moves to Ctrl+G. Ctrl+E is end-of-line again.
- R17: delete in the session browser is Ctrl+D then `y` (or Ctrl+D twice). Every letter filters.
- R3 tables: when a table is too wide, shrink the widest columns and wrap cell text inside the borders.
- Thinking entries: Enter collapses or expands them. They stay expanded by default.
- R9 and R22: move to FOLLOWUP_TASKS.

## Changes

### 1. Wrapping (`ansi.go`) - R1, R12
- Track the full SGR state (bold, italic, underline, dim, reverse, foreground, background) instead of only the last code. Re-emit the combined state on continuation lines.
- Apply SGR codes found in spaces that are dropped at a line break.
- Keep zero-width tokens (write them to the current line).
- Remove the unused `flushCur`.

### 2. Markdown (`markdown.go`) - R2, R3, R13
- Inline raw HTML is shown as text. HTML blocks are shown as plain lines.
- Code block lines are hard-wrapped to the width.
- Headings are wrapped with `WrapText`.
- Nested lists: remove the double indent (the nested list adds its own indent, so the parent's continuation indent is not added again, or the nested call uses depth 0 inside the item).
- Headings: after inline emphasis, turn the heading style back on.
- Tables: if the total width is too large, shrink the widest columns until it fits, and wrap each cell's text over several lines inside the borders.

### 3. Tool entries (`chat.go`) - R6, R11, R14, R15
- Diff lines are colored by the marker right after the line number, not by `strings.Contains`.
- Expand tabs by display column (not bytes) before wrapping, in previews and expanded results.
- The collapsed summary shows only the first line of a multi-line command, followed by `…`.
- Arg keys: `path` for read/write/edit, `task` for subagent.

### 4. File search (`filesearch.go`) - R7, R8
- Add a scroll offset so the selected row stays in the 10 visible rows.
- Score all results first, then cap to 50.
- Pass `--` before the query to `fd`.
- Exclude `.git/` in the `find` fallback.
- Remove the unused `cancel` field.

### 5. Input fixes - R4 gap, R16, R17, R18, R19
- Strip `\r` from external editor text.
- Backspace removes one character (rune), not one byte, in `selectlist.go` and `config_wizard.go`.
- Session browser: Ctrl+D starts delete; `d` filters like any other letter.
- External editor on Ctrl+G; Ctrl+E reaches the editor's end-of-line.
- `/resume`: refuse to delete the active session, and show the error when `os.Remove` fails.

### 6. Config overlay - R20
- Use `maxH` to clip the overlay to the screen and scroll with arrow keys and PgUp/PgDn. Call `SetMaxH` on resize, like the help overlay.

### 7. Small performance fixes - R21, R23
- Highlight cache: do not cache a code block that is still streaming (the last block of an entry still in flight). Evict one entry at a time instead of clearing the whole map.
- Wheel: keep one idle deadline and schedule a new timer only when none is pending.

### 8. Thinking entries
- Enter on a thinking entry collapses it to one dimmed summary line, and Enter again expands it. Default stays expanded.

### 9. Clean-up
- Remove `paste.go` and its test, and the unused `style.Theme` fields.
- Fix the stale comments in `tokens_overlay.go:31` and `chat.go:313-315`.

### 10. Tests and docs
- Write a failing test first for each fix, then refresh golden snapshots with `-update` and review the diff.
- Update help and README for Ctrl+G, Ctrl+D in the session browser, and thinking collapse.
- Add status lines to section 7 of the audit, like the other sections. Mark R10 as not a live bug and R4 as fixed by S5.
- Add R5, R9 and R22 to `docs/FOLLOWUP_TASKS.md`.
